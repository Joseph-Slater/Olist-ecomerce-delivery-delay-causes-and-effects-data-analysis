# Olist eCommerce delivery delay causes and effects data analysis

This data is real world data released by Olist onto kaggle with personal information extracted. 

I conducted this project in order to build my data analytics, python, and machine learning skills, so I tried a variety of new features for my analysis. For example I created a map which plotted the average delivery delay in different locations. I also programmed, trained, and tested a random forest prediction model to predict whether a delivery would be late based on its weight and volume. I also heavily focused on trying to visualise the data so it would be easy to follow and present to other people.
